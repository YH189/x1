# X1

A landing page design inspired by XAI website, built entirely with HTML and CSS.

## About

This project was built as a personal practice exercise to explore modern web design patterns — dark theme aesthetics, bento grid layouts, and subtle motion — without relying on any frameworks or JavaScript libraries.

## Live Demo

https://x1-web.netlify.app/

## Built With

- HTML5
- CSS3
- JavaScript

## Development Process

The core structure, styling, and layout were written by hand. AI tools — Grok, Claude, and GPT — were used selectively for debugging CSS issues, cross-checking responsive behavior, and reviewing code quality during development.

## Purpose

This is not a production product. It exists to practice frontend fundamentals: layout systems, responsive design, typography, and visual hierarchy, using a real-world reference as design inspiration.
